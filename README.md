# blockchat

blockchat 是一个 Web3 持仓聊天室原型。用户可以通过 Web3 钱包连接 Ethereum Mainnet，进入不同 token 对应的聊天室，并在聊天中用地址头像和持仓排名光环作为身份表达。

项目当前是前端 Demo，重点验证产品交互、聊天室样式、钱包余额扫描、持仓发言门槛、成员身份展示和聊天室治理流程。

## 技术栈

- React
- TypeScript
- Vite
- Yarn
- Web3 钱包注入对象 `window.ethereum`

## 本地运行

安装依赖：

```bash
yarn install
```

启动开发服务：

```bash
yarn dev
```

构建检查：

```bash
yarn build
```

## GitHub 自动部署

项目已配置 GitHub Actions 自动部署到 GitHub Pages。推送到 `main` 分支后，工作流会自动安装依赖、构建项目，并把 `dist` 发布到 GitHub Pages。

GitHub 仓库：

```text
https://github.com/33357/blockchat-demo
```

工作流会在首次运行时尝试自动启用 Pages，并配置为 GitHub Actions 发布源。如果自动启用失败，可以在 GitHub 仓库设置中手动开启：

1. 打开仓库 `Settings`。
2. 进入 `Pages`。
3. 在 `Build and deployment` 的 `Source` 中选择 `GitHub Actions`。

部署完成后，默认访问地址为：

```text
https://33357.github.io/blockchat-demo/
```

## 项目功能

- 钱包连接和断开：支持连接 MetaMask 或兼容 Web3 钱包，连接后读取当前账户和链信息。
- Ethereum Mainnet：默认面向 Ethereum Mainnet，支持切换链提示。
- 余额扫描：支持 ETH 原生余额和 ERC-20 token 余额读取。
- 默认聊天室：当前默认包含 ETH、USDC、USDT 三个聊天室。
- 自定义 token：支持通过搜索栏输入 ERC-20 合约地址添加 token 聊天室。
- Telegram 风格 UI：聊天室列表、顶部栏、消息气泡、输入框、个人信息弹层和管理弹层都按 TG 风格靠拢。
- token 图标：ETH、USDC、USDT 使用本地下载的 PNG 图标，并作为聊天室头像展示。
- 地址头像：用户头像由地址 hash 生成，聊天室内不直接显示完整地址。
- 排名光环：根据聊天室内已知成员持仓计算排名，并把排名融入头像光环下方展示。
- 个人信息：点击头像可查看简化地址和拥有 token 的排名信息，个人信息头像不显示光环。
- 消息输入：支持文字、快捷图标和红包入口。
- 聊天室管理：支持查看成员、管理员、剩余任期、发言持仓要求、地址类型和退出聊天室。
- 发言门槛：聊天室允许进入，发言可配置持仓要求，当前默认要求为 `0 TOKEN`。
- 管理员选举：USDC 默认无管理员，可开启 24 小时投票选举。
- 弹劾流程：有管理员时可发起弹劾投票。
- 模拟数据：内置模拟成员、持仓和消息，避免聊天室初始状态过空。

## 数据说明

当前 Demo 会把聊天室状态写入浏览器 `localStorage`。如果需要恢复初始模拟数据，可以使用页面左上角的重置按钮。

余额读取依赖浏览器钱包注入的 `window.ethereum`，需要在支持钱包插件的浏览器里使用。
